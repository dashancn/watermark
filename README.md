# i41 证件水印

纯前端、本地 Canvas 渲染的身份证、营业执照、合同截图等敏感图片防盗用水印工具。

## 特点

- 图片不上传、不保存、不经过业务服务器
- 支持 JPG、PNG、WebP
- 多图批量处理与下载
- 水印文字、颜色、透明度、字号、角度、横纵间距
- 日期、时间和文件名变量
- 实名认证、入职审核、银行开户等模板
- PWA离线使用
- 无后端、无远程模型、无分析脚本

## 开发

```bash
npm test
python3 -m http.server 8000
```

## 部署

纯静态站点，可直接部署到 Cloudflare Pages：

- 构建命令：留空
- 输出目录：`/`
- 域名：`watermark.i41.cn`
